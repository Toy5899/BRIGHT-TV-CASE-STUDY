# BRIGHT-TV-CASE-STUDY
This is a project about analyzing the viewership stats of bright-tv

## 📌 Project Overview
This project is a case study analyzing Bright TV's viewership and ratings data to uncover trends in audience behavior, program performance, and viewing patterns. The goal was to translate raw viewership data into actionable insights through dashboards and visual reporting, supporting data-driven programming and scheduling decisions.

## 🎯 Objective
- Analyze viewership and ratings trends across programs, time slots, and channels
- Identify top- and under-performing content
- Surface patterns in audience engagement (peak times, demographics, drop-off points)
- Present findings through interactive dashboards for stakeholders
